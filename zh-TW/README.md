# 《The Minimalist Entrepreneur》——Claude Code Skills

根據 Sahil Lavingia 的 [《The Minimalist Entrepreneur》](https://www.minimalistentrepreneur.com/) 製作的 Claude Code Skills。

## 安裝

在 Claude Code 中：

```
/plugin marketplace add slavingia/skills
/plugin install minimalist-entrepreneur
```

就這樣——Claude Code 會取得儲存庫，並自動註冊全部 10 個 Skills。

<details>
<summary>替代方式：從本機複本安裝</summary>

```bash
git clone https://github.com/slavingia/skills.git ~/.claude/plugins/skills
```

接著在 Claude Code 中：

```
/plugin marketplace add ~/.claude/plugins/skills
/plugin install minimalist-entrepreneur
```

</details>

## Skills

| Skill | 指令 | 使用時機 |
|---|---|---|
| **尋找社群** | `/find-community` | 尋找商業點子，或想找到自己的社群 |
| **驗證點子** | `/validate-idea` | 檢驗商業點子是否值得投入 |
| **最小可行產品** | `/mvp` | 準備打造第一個產品，或難以控制範圍 |
| **流程化** | `/processize` | 已有產品點子，想先手動交付價值再寫程式 |
| **第一批客戶** | `/first-customers` | 已有產品，需要找到前 100 位客戶 |
| **定價** | `/pricing` | 設定價格或考慮調價 |
| **行銷計畫** | `/marketing-plan` | 已達產品市場契合，準備透過內容擴張 |
| **可持續成長** | `/grow-sustainably` | 決定支出、招募或擴張 |
| **公司價值觀** | `/company-values` | 定義文化、準備招募 |
| **極簡決策審閱** | `/minimalist-review` | 檢查任何商業決策是否合理 |

## 極簡創業旅程

這些 Skills 依循書中的進程：

1. **社群**——先找到你的人群。
2. **驗證**——確認問題值得解決。
3. **打造**——先推出手動流程，再產品化。
4. **流程化**——把產品點子轉成今天就能交付的手動流程。
5. **銷售**——逐一取得前 100 位客戶。
6. **定價**——從第一天就收費。
7. **行銷**——透過內容建立受眾。
8. **成長**——維持獲利，持續發展。
9. **文化**——打造自己想住的房子。
10. **審閱**——將極簡原則運用於每個決策。
